# workspace/pages

Артефакты пайплайна страниц сайта (`page-builder` / `/page`). Одна папка на страницу:
`workspace/pages/{slug}/`.

| Файл | Что внутри |
|------|------------|
| `page.md` | Сама страница по слотам Kit, с фронтматтером `product` / `type` / `vertical` / `status` |
| `fact-sheet.md` | Источник каждого числа и каждого имени клиента + что реально измерено, а что нет. Это единственное, кроме драфта, что видит слепой судья |
| `gate-reports.md` | Результаты G-I / G-A / G-T, выброшенные слоты с причинами, вейверы с датами |
| `judge-round-N.json` | Каждый раунд слепого судьи, включая проваленные |
| `open-items.md` | Каждый погнутый гардрейл — для Ассель (принцип #11) |
| `README.md`, `TODO.md` | Пакет для того, кто публикует в WordPress |
| `assets/` | Картинки, на которые ссылается страница |
| `log.md` | Лог прогона (CLAUDE.md §10 п.5) |

Статьи сюда не пишутся — они живут в `workspace/seo/`.
