1. What we are building

  • One page at 3dlook.ai/meet-us/ where we invite people to meet us at a conference. The first event is CES 2027: booth 55630, Venetian Expo, Las Vegas, January 6-9, 2027.
  • The page is a template. We run several conferences a year. Marketing must be able to change every text, image, video, link and block for the next event in WP admin, without a developer.
  • The page is not indexed. It is a working tool for conference prep. People reach it from invite emails, LinkedIn outreach, the flyer QR, business cards and social posts. It is not in the menus, the sitemap or search.
  • Design: Kristina's Figma (links below), 4 widths. The first screen has an interactive dot background (section 4).

4. Hero: interactive dot background

The dots must react to the user. This is the main visual idea of the page.

  • Look at rest: black background with a grid of small grey dots, as in the Figma layer «Dots BG» (grid about 40 px, dots 1-3 px, different brightness, dim under a 42% black overlay). Take sizes and colours from Figma.
  • Mouse: dots near the cursor (radius about 150-200 px) grow, get brighter and turn brand blue (#143DFF at the edge of the effect, #B1BDFF near the centre). They move slightly away from the cursor. When the cursor leaves, they return to rest smoothly (about 0.5 s).
  • No cursor activity: a slow, quiet wave or twinkle across the grid, so the screen feels alive on load and on phones.
  • Touch screens: a tap on the hero sends a ripple from the tap point. Do not block page scrolling.
  • prefers-reduced-motion: static dots, no animation.
  • Text stays readable: limit the brightness of the effect behind the text block. Contrast of text against the background at least 4.5:1.
  • Tech: one <canvas> behind the hero content, plain JavaScript with Canvas 2D. No three.js, no new libraries, no plugins. requestAnimationFrame. Pause when the hero is off screen (IntersectionObserver) or the tab is hidden. Cap devicePixelRatio at 2. Load the script deferred.
  • No impact on loading: the H1 and the button render without JS. Before JS starts, the hero shows a static dot image (export of «Dots BG») as a CSS background.
  • Sign-off: Kristina approves the final motion (radius, colours, speed) on staging.

«About FitXpress» button: opens a modal with the YouTube video 452QOv0O2Hw through youtube-nocookie.com. The player loads only on click. The video ID is a field, so we can switch to the booth video in December.

5. Constructor: how the template works

  • Who fills it: Pasha fills the template for CES the first time: all texts, images, videos and Yoast settings. After launch, and for the next conferences, Asel changes the content in the fields.
  • A custom page template «Event page» in the theme (/wp-content/themes/3dlook/). All content comes from custom fields: use what the theme already uses for fields (ACF, if it is installed). No Elementor.
  • No new plugins. Vadim's rule for 3dlook.ai. If something cannot be done without one, ask Vadim first.
  • HTML is rendered on the server. JS only adds behaviour (dots, tabs, video, modal).
  • Every block has a Show / Hide switch. Hidden blocks leave no gaps and no empty markup.
  • Anchors (#find, #book) are fields with these defaults.
  • More than one page can use the template at the same time, for example the live event and a draft for the next one.
  • Field labels in English, with a short hint: image sizes, character limits, where the text appears.

6. Find us: route map

  • Tabs: «Hall D entrance» and «Hall C entrance». Labels only: remove «about 230 m» and «about 200 m» (Vadim's decision, still in Figma). Default tab: Hall D entrance.
  • Video: <video autoplay muted loop playsinline> with a poster. No controls, no Replay button, no distance or walking time, no note under the map. The route animation loops by itself (11.4 s).
  • A tab switch swaps the video and the steps and starts the new video from the beginning.
  • The steps are an ordered list. Their numbers match the numbers on the map.
  • Load the video only when the block gets close to the screen. Until then, show the poster. Reserve the space (aspect ratio 1600:1272) so the page does not jump.
  • prefers-reduced-motion: poster only, no autoplay.
  • The video is decorative for screen readers (aria-hidden). The steps carry the information. Tabs: role="tablist", aria-selected, arrow keys.
  • Pasha downloads the files from the Drive folder (anyone with the link can view and download) and uploads them to the WordPress Media Library. Do not link to Google Drive.
  • Note: in the Figma 1440 frame, the Hall D tab shows the west poster. Use the foyer files for Hall D.

8. Book a meeting (#book)

  • The calendar in Figma is a mock. The real widget is HubSpot Meetings in an iframe: round robin between Katerina and Whitney, 15-minute slots, January 6-9. Page CSS does not reach inside the iframe. Build the left column and a container the size of the mock, and the widget fills it. Do not build a custom calendar or use HubSpot's internal booking API.
  • Embed code:
    <div class="meetings-iframe-container" data-src="https://meetings.hubspot.com/katerina-galich/booth-55630?embed=true"></div>
    <script type="text/javascript" src="https://static.hsappstatic.net/MeetingsEmbed/ex/MeetingsEmbedCode.js"></script>
    The URL comes from the Booking field. The script loads only when the block exists.
  • Time zone line next to the widget: «Times show in your time zone. Pick Pacific Time in the menu to see Las Vegas time.» The widget shows the visitor's local time, and before the show almost nobody is in Las Vegas yet.
  • Code block: heading «No CES badge yet?». Text: «Use our code [code: in the Google Doc only, kept out of this repo] for $149 off CES registration. Valid until December 31.» Link «Register for CES» → https://registration.experientevent.com/showCES271/Wizard/Landing. The code is case-sensitive: copy it exactly. Never write «free». The block goes off on January 1, 2027.
  • Soft link: «Not going to Las Vegas? Request an online demo instead.» → https://3dlook.ai/contact-us/
  • Exclude MeetingsEmbedCode.js and the dots script from delayed JS (WP Rocket «Delay JS» and Flying Scripts). Otherwise the widget appears only after the first scroll or click. Test the widget with cookies accepted and with cookies not yet accepted (WebToffee banner).

10. Indexing and SEO

  • Yoast: noindex, follow. Yoast leaves noindex pages out of the sitemap by itself.
  • Make noindex the template default in code (Yoast robots filter), so a new event page can't get indexed by mistake.
  • Do not block the URL in robots.txt: Google has to read the noindex.
  • Not in the header, footer or any menu. Not in site search, related posts or other automatic lists.
  • No schema markup.
  • Title and meta description per page in Yoast. CES: «Meet 3DLOOK at CES 2027 · Booth 55630». OG image 1200×630 from Kristina, set in Yoast.
  • The slug stays /meet-us/. No «CES» in URLs (CTA contract).

12. Quality bar

  • The 4 Figma widths (1920, 1440, 744, 375). Fluid in between, no horizontal scroll.
  • Satoshi and the colours from the theme. Visible keyboard focus (ring #B1BDFF, 3 px).
  • Mobile: LCP under 2.5 s, CLS under 0.1. Video and widget space reserved.
  • Tested in Chrome, Safari (macOS + iPhone), Firefox, Edge, Android Chrome.
