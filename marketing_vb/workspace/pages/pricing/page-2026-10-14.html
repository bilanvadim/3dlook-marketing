How FitXpress counts API requests

A request is one API call that creates a new result. All request types draw from the plan's monthly pool. Retrieving results, checking scan status and checking usage do not use requests.

BMI check at intake

An online pharmacy verifies BMI once for each new patient. Each patient uses one body scan.

450 patients a month = 450 requests, within Starter

Monthly progress check-in

A weight-management program scans each member once a month and shows a 3D progress comparison with the previous scan.

300 members, each with 1 scan and 1 comparison = 600 requests, within Pro

Data storage, retention, HIPAA, GDPR and security audits are covered in full in the Data, Privacy, Security & Regulatory FAQ.

Billing and plans

What is an API request?

A request is one call to the FitXpress API that creates a new result: a body scan, a 3D goal visualization, or a body progress comparison in 3D or 2D. Each one uses one request from the plan's monthly pool. Retrieving results, checking scan status and checking usage do not use requests.

How many requests does one person use?

It depends on the workflow. A one-time BMI check uses one request. A monthly check-in with a 3D progress comparison uses two requests a month. Showing both the 3D and the 2D comparison for the same two scans uses one request for each format.

How do we track request usage?

The API reports requests used and requests remaining for the current subscription at any time, broken down by request type. Volumes above 1,000 requests a month move to a Personalized plan with volume pricing.

Is there a free trial?

There is no self-serve trial. After a demo call, the team gets hands-on access to a demo page to run scans and review the outputs. Once the contract is signed, the first month is free for integration and testing. Billing then follows the plan.

Is there an integration or setup fee?

No. FitXpress plans have no integration fee. The plan price covers the API, the iOS, Android and React SDKs, and guided implementation support.

Product

What does one body scan return, and how fast?

One scan returns 80+ body measurements, body composition estimates including BMI, BMR, body fat percentage, lean mass and fat mass, and a 3D body model. FitXpress delivers structured results in under 45 seconds from the photos.

How accurate is FitXpress?

Internal validation across multiple real-world scan events with five repeated scans per person against expert pattern-maker manual measurements shows 3DLOOK's measurement accuracy of approximately 96-97% across body metrics, with a typical absolute error of 1.5-2.0 cm per measurement, varying by body part. The method is described in Body Scanning Accuracy.

What integration does FitXpress require?

FitXpress runs inside the client's own app or website. The SDK handles the guided photo capture, and the API submits scans and returns results. 3DLOOK provides API documentation and guided implementation support on every plan.

How is scan data protected?

Photos are deleted immediately after processing or within 30 days under the client's policy, and retained photos are automatically blurred. FitXpress can support HIPAA-governed deployments where 3DLOOK acts as a business associate under an executed business associate agreement (BAA). In most enterprise deployments, the customer acts as the data controller and 3DLOOK acts as the data processor under GDPR.

FAQ

Mobile Tailor pricing questions

Billing and plans

What counts as a billable scan?

Mobile Tailor bills successful scans. One successful scan is one person's front and side photos processed into measurements, and every output for that scan comes with it.

Do I need to integrate Mobile Tailor with my business backend to use it?

No. Mobile Tailor is a software-as-a-service (SaaS) solution that requires no integration. Once a plan is selected, Mobile Tailor is ready to use. The Enterprise plan includes an API and SDKs for teams that connect it to internal systems.

Product and scanning

How does Mobile Tailor work?

Businesses send a scanning link by email or SMS from the Mobile Tailor Admin Panel, or embed a measurement widget on their site or product pages. The link guides the person through a front and side photo capture. The measurements appear in the Mobile Tailor Admin Panel as soon as the scan is processed.

How long does it take to scan?

A scan takes under 3 minutes. Measurements appear in the admin panel as soon as the scan is processed.

What if the person is alone? How do they scan?

There are two options: "With a friend" mode, where another person takes the photos, and "Hands-free" mode, where voice guidance walks the person through the scan with the phone set at an angle on a desk-high table.

Are there specific clothing requirements?

Mobile Tailor works best with tight-fitting bottoms (for example, leggings) and tops (for example, a tight T-shirt, tank top or sports bra).

Can we upload existing photos?

No. Mobile Tailor requires the scanning link, which uses the phone's gyroscope to control the camera angle during capture. That control is what keeps measurements consistent.

Can users check their measurements?

Yes. All measurements appear in the Mobile Tailor dashboard when the scan completes. To share them with the person who scanned, enable "User Measurements" in the admin panel under Widget Settings, then Final Screen.

How do you address privacy?

Photos are used only to generate 3D models and measurements. To delete photos, send a deletion request to privacy@3dlook.me.
