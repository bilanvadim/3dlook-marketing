## Format decision
**Recommended:** carousel, 3 slides — per the post's own Design tip, not overridden.
**Why:** Olena's post argues a three-beat case for a European BD audience — variability compounds across a multi-country trial, a hybrid/remote workflow needs to be GDPR-sound by design, and the payoff is one comparable record set. A single static image can carry a stat but not this problem → constraint → outcome sequence; a swipe-through lets each beat land on its own slide before the reader reaches the "open to connect" CTA in the caption. This also matches the article's own three-element OG composition (dot-map, guided-scan icon, timestamp/record icon), so the carousel reads as a direct, sequenced unpacking of the article banner rather than a new visual system.
**Dimensions:** 1080×1080 px (square), consistent across all 3 slides for a LinkedIn carousel/document post. Master each slide at 1350×1350 if extra resolution is needed for repurposing; do not switch aspect ratio mid-carousel.

## Visual concept
**Big idea (1 sentence):** A trial spread across several European countries only stays comparable if the capture step is standardized and GDPR-sound from the start — shown as one visual system (dot-map → guided-scan + lock → timestamped record) across three slides.
**Mood:** serious, operational, European-institutional — "trial infrastructure for a multi-country program," not consumer-fitness, not alarmist about compliance.

## Composition
General frame carried across all 3 slides for carousel continuity:
- Full-bleed dark teal-blue background (see Colors below) — identical treatment on every slide so the swipe reads as one object.
- Center-weighted single visual motif per slide (see Carousel breakdown) — one idea per slide, generous negative space, no crowding.
- Bottom-right: 3DLOOK or FitXpress wordmark badge, small, present on every slide (per the source article's OG brief instruction that the badge is consistent across content-hub visuals). No logo file currently exists in `brand-assets/` — designer to source the current lockup from the Figma website file or confirm with Vadim before placing.

## Typography
- Headline (per slide): Inter Bold or Black (per `fonts.md`) — large, tight tracking, sized to dominate each slide.
- Sub (per slide): Inter Regular or Medium, ~40-50% the headline size.
- Max 2 font weights per slide; no third typeface; keep type scale identical across all 3 slides for carousel cohesion.

## What NOT to do
- No stock-photo "people in office / clinicians shaking hands."
- No generic AI-illustration purple-pink gradients.
- No Font Awesome-style icons stacked on top of text.
- No patient/participant face or realistic body imagery on any slide.
- No real map, no traced country borders, no country labels or flags on slide 1 — the "several European countries" idea must stay abstract (a loose cluster of connected dot/node markers suggesting distribution across a region), never a literal geographic map that could be read as identifying a specific trial's site locations.
- No stock "cybersecurity" padlock badge or shield-with-checkmark clipart on slide 2 — keep the lock/shield mark a simple, thin-line abstract mark consistent with the icon language of the other two slides, not a decorative security icon.
- No DEXA-style scanning imagery anywhere.
- Don't let slide-to-slide backgrounds or type scale drift — the 3 slides must read as one continuous object when swiped, and must visually connect back to the article's OG banner (same dot-map / guided-scan / timestamp-record vocabulary).
