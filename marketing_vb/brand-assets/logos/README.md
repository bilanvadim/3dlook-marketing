# 3DLOOK logo files

| File | Use |
|---|---|
| `3dlook-logo-black.svg` | **Primary** horizontal lockup (symbol + wordmark) on white / light backgrounds |
| `3dlook-logo-white.svg` | Horizontal lockup on navy, black, electric blue or darkened imagery |
| `3dlook-symbol-black.svg` | Symbol alone (avatars, tight spaces) on light backgrounds |
| `3dlook-symbol-white.svg` | Symbol alone on dark backgrounds |

**Source.** The wordmark is the production header logo of 3dlook.ai (248×36 viewBox, inline SVG in the header;
the white file was already used by `brand-assets/video/stat-reel.html`). The symbol is the site's
`uploads/2025/04/icon-3dlook-svg.svg`. The black lockup and the white symbol are the same paths with the fill
switched, which the brand guideline allows (the logo is always black or white). Collected 2026-11-12.
The master file is the Figma file «3DLOOK-logo» (`HnZOyPwutxybq0LXXNcbbq`), linked from the guideline's
Download button; re-check against it when Figma access is on.

**Rules (brand guideline, Google Slides «3DLOOK Branding» `1p1cW9pE-a4nvqlRRUzirIU6tvSksz7T20YxaFMAuEQ4`, slides 6-9):**
- The horizontal lockup is the primary logo; use it in most cases. Never use outdated versions.
- Clearspace: keep empty space around the logo on all sides (the guideline shows it as the height of the
  symbol's inner triangle); nothing else enters that zone.
- Minimum size: horizontal lockup **90 px wide**, symbol **20 px high**.
- **The logo is always black or white.** No blue logo, no gradients, no colour change.
- Don't: narrow, widen, rotate (whole or parts), change the symbol-to-wordmark distance, mirror, make the
  symbol 3D, add gradients, special effects, drop shadows, outlines, or crop it.
- Backgrounds: white, colour, dark or imagery are all fine if the logo stays legible. Use the contrasting
  version; if an image doesn't contrast, darken or lighten the image until it does.

**Known issue (2026-11-12):** the site favicon (`uploads/2023/10/cropped-3dlook-black-logo-1-*.png`) is the old
3D version of the symbol, which the guideline lists as a «don't». Not copied here; replacing it is a site task.

Product names (FitXpress, Mobile Tailor, Wrist Measurement) have no separate logo files; they are set in text
next to the 3DLOOK logo, in the product's colour from `DESIGN.md` §2.
