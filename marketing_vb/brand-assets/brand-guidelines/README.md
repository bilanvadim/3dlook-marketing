# 3DLOOK brand guideline — where it lives

The official guideline is a Google Slides deck, not a file in this repo:
**«3DLOOK Branding»** `1p1cW9pE-a4nvqlRRUzirIU6tvSksz7T20YxaFMAuEQ4` (Vadim's copy, 2026-05; original by
Kristina Nazarevska, 2024-02, `1nalVJelEHJYf1zfGp_BVHqO8ial3UbNOVDhN6aNqaeo`).

Every rule from it is folded into `DESIGN.md` (read that, not the deck):
- logo: lockup vs symbol, clearspace, minimum size, always black or white, misuse list → `DESIGN.md` §10 + `brand-assets/logos/README.md`
- colours: black / white primary, `#F3F3F3` neutral, `#143DFF` accent → `DESIGN.md` §2 (same values)
- type: Satoshi official (Light / Regular / Medium / Bold, no 600), Jost secondary for decks and the
  Mobile Tailor widget → `DESIGN.md` §3, §3b
- icons, photography, presentation rules → `DESIGN.md` §10

Not ours: «Brand Guideline.pdf» on Drive (2026-10-22) is the Activitis Education brand book. The 2021
«3DLOOK Brand Identity Guidelines» PDF is superseded.
