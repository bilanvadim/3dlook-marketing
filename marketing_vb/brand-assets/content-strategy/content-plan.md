## How agents use this file

Before any new FitXpress article, `seo-planner` (Phase 0) and `context-pack-builder` (track=seo) **must locate the topic's row here** and carry these fields downstream:

- **Main hub topic** — the authority page this piece belongs under (every supporting article links up to it).
- **Cluster section** — the narrow slot inside the hub.
- **Intent** — Hub / TOFU / MOFU / BOFU / GEO-comparison / listicle / objection handling / conversion / Tool → sets depth and CTA. (The sheet's «Intents system» tab lists the combined values.)
- **Action Type** — the writing instruction (see legend). **This is a gate**, not a suggestion.
- **Execution Priority** — P0 (backbone) · P1 (strong supporting) · P2 (conditional: validate demand or start as a hub section) · `P0/P1/P2 - published` (live; maintain, don't recreate).
- **Pages** (`URL of already published articles`) — refresh target, internal-link source, or cannibalization warning.
- **Recommendation** — the specific angle and decision for this row. A leading `Condition: …` is part of the gate.
- **Cannibalization guardrail** — hard boundary, quoted word for word in `plan.md`; a new page must not duplicate what already owns the intent.
- **Demand / KD** — the evidence behind the priority. Use it for the keyword brief; it does not override Phase 1 keyword research.

**A title without its strategy row is not a brief.** If the topic is not in this plan, `seo-planner` stops and asks Vadim to place it (hub + cluster + action type) before proceeding.
