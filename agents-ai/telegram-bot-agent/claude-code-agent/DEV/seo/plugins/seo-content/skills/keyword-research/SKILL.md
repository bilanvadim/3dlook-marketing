# Keyword research → intent → clusters → brief

Volume is a distraction until you know intent and can win the SERP. Work in this
order.

## 1. Seed & expand
Start from the business's products/problems, competitor coverage, GSC queries
already getting impressions, and "People also ask"/autocomplete. Group raw
keywords into topics, not a flat list.

## 2. Classify intent (the pivot)
Label each query:
- **Informational** — learn ("how to…", "what is…") → guides, articles.
- **Commercial** — compare/evaluate ("best…", "X vs Y", reviews) → comparisons,
  listicles.
- **Transactional** — act/buy ("buy…", "pricing", "near me") → product/category/
  landing pages.
- **Navigational** — a specific brand/site.
A page that matches the dominant intent of its target query wins; a mismatch does
not, regardless of effort.

## 3. Read the actual SERP
For the target query, fetch and inspect the current results: what content type
ranks (guide vs product vs video), depth, format, SERP features (featured
snippet, PAA, images, shopping), and difficulty (are these sites you can realistically beat?). Base the plan on this reality.

## 4. Build topical clusters
- **Pillar** page for the broad topic/head intent.
- **Supporting** pages for specific sub-queries/long-tail, each a distinct intent.
- Interlink pillar↔supporting with descriptive anchors → topical authority.
- **One primary intent per URL.** If two candidate pages target the same intent,
  merge or differentiate — this is how you prevent cannibalization up front.

## 5. Content brief (the deliverable)
For each target page:
- Primary query + intent; secondary queries/entities to cover.
- Audience & angle; the job the page does.
- Must-cover subtopics, questions (PAA), and entities (from the SERP).
- Suggested title (CTR-oriented, honest) + meta description.
- Internal links in/out (which cluster nodes, what anchors).
- E-E-A-T signals to include (author expertise, sources, first-hand experience).
- Target depth/format matched to the winning SERP results (not an arbitrary word
  count).

## Anti-patterns
Chasing volume over intent · two pages for one intent (cannibalization) · thin
programmatic pages · keyword stuffing · ignoring the SERP and writing blind ·
briefs with a word-count but no entities/intent.

## Hand-off to measurement
Every brief names its target metric (impressions/position for the primary query,
CTR from title/meta, assisted conversions) so `seo-analyst` can baseline and
measure — remembering indexation + ranking lag is weeks, not days.
