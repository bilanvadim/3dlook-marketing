# Paid media — plan, test, optimize (profitably)

Budget is a loan you repay with customers. Prove payback small, then scale — never
the reverse.

## 1. Media plan
- Pick channels by **audience + funnel stage**: search (high intent, capture
  demand), paid social (create demand, targeting/creative-led), display/video
  (awareness/retargeting).
- Allocate budget to a **target CPA/CAC and ROAS** per channel; estimate volume.
- Define the **conversion goal** and confirm tracking exists first.

## 2. Campaign structure
- Clean hierarchy: account → campaign (by objective/funnel) → ad set (by
  audience) → ads. Don't mix prospecting and retargeting budgets.
- Audiences: prospecting (interests/lookalikes/keywords) vs retargeting
  (visitors/engagers/cart). Exclusions to avoid overlap.
- Start consolidated (let the algorithm learn); avoid over-segmenting tiny budgets.

## 3. Creative testing
- One **hypothesis**, one **variable** per test (hook, angle, format, audience).
- Enough **data** before a verdict (meaningful conversions/spend + time, not a day
  of noise). State the sample and window.
- Brief winners/needs to `content-marketer`; keep a creative refresh cadence to
  beat fatigue (watch frequency).

## 4. Economics & scaling
- **CAC < LTV** is the gate. Compute payback period. Scale winners in steps
  (~20–30% budget increases) to avoid resetting learning; cut losers fast.
- Watch diminishing returns as budget grows (CPA creep) — more spend ≠ linear
  return.

## 5. Message match & landing
Ad promise must match the landing page (scent). Mismatch burns budget. Coordinate
with the landing page (dev/`verification-protocol` if code) and content.

## Anti-patterns
Scaling before payback proven · launching without conversion tracking · multi-
variable tests → unreadable · declaring winners on noise · budget fragmentation ·
ad/landing message mismatch · ignoring frequency/fatigue · prohibited claims/
targeting (policy strikes).

## Gates & hand-off
All live-account actions (launch, budget/bid changes) are PROPOSED and human-
approved. Baseline + measure with `marketing-analyst` (CPA/CAC, ROAS, incremental
lift where possible), honest about attribution.
