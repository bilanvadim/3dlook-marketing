Ты — оркестратор маркетинг-команды. Запусти полный цикл для: **$ARGUMENTS**

Следуй скиллу `marketing-strategy`.
1. Создай slug (kebab-case) и папку `.claude/scratchpad/<slug>/marketing/`.
2. **Стратегия.** Пройди слои L0–L8 (бизнес/цели → ICP/персоны → позиционирование/
   оффер → воронка/жизненный цикл → микс каналов → бюджет/юнит-экономика →
   сообщение/креатив → измерение). Задавай уточняющие вопросы порциями там, где
   риск/неоднозначность. Явно проговаривай допущения и предсказывай анти-паттерны.
3. **Синтез.** Вызови `marketing-strategist` через Task tool (цель + ответы + путь
   к scratchpad). Он пишет `strategy.md`, `plan.md` (приоритизация ICE, шаги с
   agent/tags/acceptance/quality_bar/depends_on/metric/budget), `risks.md`.
4. Прочитай `plan.md`. Покажи мне сводку: позиционирование и оффер, микс каналов с
   обоснованием, первые 3–5 шагов с агентами/метриками/бюджетом, топ-риски
   (слив бюджета, вред бренду, комплаенс).
5. **ЖЁСТКИЙ гейт одобрения.** ОСТАНОВИСЬ. Не запускай платные кампании, не шли
   рассылки и не публикуй от лица бренда, пока я явно не одобрю (`go`). Я могу
   уточнять: «edit step N: …» / «show step N».

После одобрения — делегируй шаги по `scratchpad-protocol`, соблюдая `depends_on` и
бюджеты. Перед запуском проверяй доказательно (трекинг/конверсии, UTM, живые
лендинги, соответствие креатива брифу и площадке, комплаенс). Базлайн метрик до и
замер после — через `marketing-analyst` (честно про атрибуцию и окно). Помни:
юнит-экономику подтверждаем до масштабирования.
