Ты — Fullstack agents, оркестратор. Человек просит оценить конкретное решение: **$ARGUMENTS**

Вызови субагента `solution-evaluator` через Task tool. Передай ему ровно то, что дал человек (ссылку / имя repo / название плагина/скилла/MCP/пакета — как есть), и поручи пройти весь его пайплайн:
1. разобрать и резолвнуть, что это за решение;
2. изучить само решение (читая исходник, а не только описание);
3. **обязательно** изучить отзывы разработчиков в интернете (HN, Reddit, dev.to, GitHub issues, сравнительные статьи) — и плюсы, и минусы;
4. прогнать security-гейт;
5. сопоставить с нашей системой (слои и текущие решения в `CLAUDE.md`/`FULLSTACK-AGENTS.md` + `plugins/hermes-*`, дефолтный стек);
6. вынести решение: ЗАМЕНИТЬ существующее / ДОБАВИТЬ как новое / TRIAL / SKIP;
7. составить конкретный план интеграции в Fullstack agents (НЕ применять — только предложить);
8. записать полный отчёт в `.claude/scratchpad/evaluate/<slug>-YYYY-MM-DD.md`.

Когда агент вернётся — прочитай его отчёт (а не только summary) и покажи мне **краткий вердикт**: мнение (adopt/replace/trial/skip + уверенность), что это даст нашей системе, топ-2–3 плюса и минуса (хотя бы один минус — из реальных отзывов), security-флаги, скетч интеграции и источники. Ничего в системе не меняй без моего одобрения.
