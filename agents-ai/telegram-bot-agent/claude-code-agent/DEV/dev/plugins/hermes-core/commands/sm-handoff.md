Ты — оркестратор Fullstack agents. Напиши **структурный session-handoff** для: **$ARGUMENTS** (если пусто — текущая работа этой сессии). Следуй скиллу `session-handoff` (Tier 2).

Собери из этой сессии и из `.claude/scratchpad/` и запиши в `.claude/scratchpad/_handoff/latest.md` (и копию `_handoff/handoff-<дата-время>.md`) документ со строго этими секциями:
- **Goal** — что в итоге делаем.
- **Done** — что завершено и проверено (с доказательством/путями/коммитами).
- **Tried & rejected** — что пробовали и почему НЕ сработало (чтобы не повторять).
- **Key decisions** — выбрано + отклонённая альтернатива + почему.
- **Next steps** — конкретные следующие 3–5 действий по порядку.
- **Watch out** — ловушки, хрупкие места.
- **Files & state** — ключевые пути, ветка, что закоммичено/запушено, открытые scratchpad'ы.

Правила: коротко и по делу; источник истины — код и feature-scratchpad, handoff лишь указатель+сводка; не выдумывай «сделано» без доказательства. После записи покажи мне путь и краткую сводку. Этот файл `latest.md` автоматически подхватится хуком `session-handoff` при старте следующей сессии (после `/clear`/сжатия).
