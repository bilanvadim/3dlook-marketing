# OpenCode — запасной кодинг-агент

Роли в стеке: **Claude Code** — основной исполнитель, **OpenCode** — запасной, когда
Claude упирается в лимиты. Модель для него выбирается каждое утро роутером Hermes
(см. `../hermes-agent/MODEL-ROUTER.md`), а не задаётся вручную.

## Файлы

| Файл | Что это | Кто пишет |
|---|---|---|
| `~/.config/opencode/opencode.jsonc` | `model` + `small_model` | **роутер, каждое утро** |
| `~/.local/share/opencode/auth.json` | ключи провайдеров (0600) | роутер (ключ победителя) + `opencode auth login` |

В репозитории лежат только `*.example` — реальные файлы содержат ключи.

## Три условия, без которых `opencode run` молча ничего не делает

Все три выглядят одинаково — **exit 0 и пустой stdout**, ни строчки ошибки:

1. **Нет кредов провайдера** в `auth.json` для провайдера из `model`.
   Проверка: `opencode auth list` должен показать нужного провайдера.
2. **`small_model` платная.** OpenCode перед каждым запуском генерирует заголовок
   сессии встроенной моделью `gpt-5-nano` — она платная на zen, при нулевом балансе
   даёт `401 CreditsError`, и стрим умирает вместе со всем запуском.
3. **Запуск вне git-репозитория.** Вне проекта `opencode run` не делает ничего.
   Всегда `cd <repo> && opencode run '<задача>'`.

Проверка живости:

```bash
cd @DEST@ && opencode run 'Reply with exactly: BACKUP-OK'
# → BACKUP-OK
```

## Как его вызывает Hermes

По политике из скилла `vps-orchestration`: при лимите Claude пишется
`<workdir>/.hermes-handoff.md`, коммитится всё недоделанное, затем **без флага `-m`**
(модель уже в конфиге) запускается `opencode run` в том же репозитории. Префикс
провайдера у бесплатных моделей — `opencode/*` (zen) или `google/*`, `openrouter/*`,
`nvidia/*`; список — `opencode models`.

Платный тир `opencode-go/*` выведен из эксплуатации — стек полностью бесплатный.
