# Content calendar & copy method

Content earns attention and moves people through the funnel — plan it, don't just
publish.

## 1. Pillars → personas → stages
- Define 3–5 **content pillars** from positioning (what you want to be known for).
- Map each pillar to **personas** (from `strategy.md`) and **funnel stages**:
  - **Awareness** — educational/entertaining, problem-aware; broad reach.
  - **Consideration** — comparisons, how-tos, proof, use-cases.
  - **Conversion** — offers, demos, case studies, testimonials.
  - **Retention/Referral** — onboarding, tips, community, advocacy.
Balance the calendar across stages; most brands over-index on awareness and starve
conversion.

## 2. Editorial calendar
Columns: date/cadence · pillar · persona · funnel stage · format · channel ·
owner · CTA · status. Set a realistic **cadence** you can sustain (consistency >
bursts). Batch production.

## 3. Copy structure (any format)
**Hook** (earn the next line) → **Value** (the useful thing) → **Proof** (data,
example, testimonial) → **one clear CTA**. Cut fluff. Lead with benefit, not
feature. Write to one persona, in brand voice.
- Ads: hook + single promise + CTA, matched to the landing page.
- Landing: headline = the promise; sub = who it's for; proof; one CTA above the fold.
- Email: subject earns the open; one idea; one CTA (coordinate with lifecycle).
- Social: native format, front-load the hook, no external-link-buried value.

## 4. Atomize & repurpose
Plan one **pillar asset** (guide, study, webinar) then atomize: → social posts →
email → short clips → snippets → threads. One effort, many placements. Note which
derivatives each pillar spawns.

## 5. Distribution
Owned (site/blog/email) + earned (organic social/PR) by default; flag assets worth
**paid amplification** for `paid-media-buyer`. Adapt per channel (specs, tone,
length). Publishing is not distribution — plan the push.

## Anti-patterns
Publishing without distribution · all awareness, no conversion content · multiple
CTAs per asset · feature-dumping · off-brand voice drift · unsustainable cadence ·
fabricated proof/urgency · ignoring repurposing (one-and-done).

## Hand-off to measurement
Each asset names its target metric (engagement, CTR, assisted conversions, email
open/click) so `marketing-analyst` can measure contribution.
